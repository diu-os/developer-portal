Author a gene

A gene is a passport, gene.json, checked by the public kernel. The kernel decides whether the passport is complete. It does not run the scientific model. The commercial distribution is diu-os.com: that is where a scientist records a run or orders a check. The charter is diu-os.org. This host is only the open checker.

What the kernel checks

  • digest — canonical JSON (RFC 8785) then SHA-256. The client does not supply the digest.
  • gate1 — the passport is complete: identity, purpose, equations, a real DOI, ports, units on numeric ports, an epistemic ceiling, limitations, and one verification check.
  • epistemic — fact, hypothesis, speculation, unknown. The ceiling does not rise. On a gene the ceiling stays at hypothesis.
  • Verification here means the passport and a later run were computed as specified. It does not mean the model is adequate to the world.

gene.json

  • identity.module_id — lowercase, digits, underscores; 3–64 characters, starting with a letter.
  • identity.version — MAJOR.MINOR.PATCH. identity.title — required, at most 120 characters.
  • scientific_purpose — at least 40 characters.
  • mathematical_model.equations — at least one equation. source_doi is required with equations, in the form 10.<registrant>/<suffix>. Use a DOI that exists. Do not invent one.
  • At least one input and one output. A numeric port carries a unit.
  • known_limitations — at least 40 characters. verification_test — at least 20 characters, one check someone else can rerun.

A passing local check yields a candidate pin: identity, revision, content hash. A candidate pin is not a row in the module registry.

Clone the kernel

You need Rust (stable) and git. The pin is git tag v0.1.0, commit 2cdda70eb3c69918e5c6e9d90817617c0387e935. GitHub’s Releases page lists no release asset. git checkout v0.1.0 is the checkout. The diu binary is not in this crate. 

git clone https://github.com/diu-os/diu-kernel.git
cd diu-kernel
git checkout v0.1.0
cargo test

cargo test compiles the library you are about to call: diu_kernel::gate1::validate_gate1 and diu_kernel::digest::canonical_digest. License: Apache-2.0.

Without building Rust

diu-os.com/#/write-your-gene asks for the passport in ordinary language and downloads gene.json. It does not run the model and it does not upload the file.

License

The kernel is Apache-2.0. That is the license for this checker. The Sepolia contract snapshot is MIT and is a different tree. The platform — API, frontend, engines — is not published under either license.

What this host is not

  • There is no public HTTP API, MCP server, or SDK here.
  • There is no CDC pipeline and no api.diu-os.org.
  • diu-docs is not the documentation.
