Core Architecture Principles

DIU OS is built on battle-tested architectural patterns designed for scalability, maintainability, and real-time collaboration.

🎯

Domain-Driven Design

Strategic design with bounded contexts ensuring clear domain boundaries and ubiquitous language across the scientific platform.

  • 5 Bounded Contexts: Identity, Research, Simulation, Funding, Publishing
  • Aggregate roots with domain events
  • Repository pattern for data access
  • Domain services for complex logic
⚡

Event-Driven Architecture

Asynchronous communication between services using domain events, enabling loose coupling and real-time reactivity.

  • Event sourcing for audit trail
  • CQRS for read/write separation
  • Eventual consistency model
  • Event replay for debugging
🔷

Microservices

Independent Rust services aligned with bounded contexts, each with its own database and deployment lifecycle.

  • Service per bounded context
  • Independent deployments
  • API Gateway routing
  • Service mesh ready
🔄

CDC Pipeline

Change Data Capture with Supabase ETL capturing every database change and streaming it to all subscribers in real-time.

  • PostgreSQL WAL → Redis Streams
  • <100ms end-to-end latency
  • WebSocket broadcast to clients
  • Dead letter queue for failures
🤖

MCP Protocol

Model Context Protocol integration enabling any LLM to interact with simulations, knowledge bases, and research tools.

  • Vendor-agnostic AI integration
  • 3 MCP servers: Physics, Knowledge, Progress
  • Tools, Resources, Prompts primitives
  • JSON-RPC 2.0 over stdio/HTTP

System Architecture

DIU OS combines DDD bounded contexts with event-driven microservices, connected through a real-time CDC pipeline. Select a component to learn more.

Full Stack Architecture

Client applications connect through an API Gateway to Rust microservices. All changes flow through the CDC pipeline for real-time updates.

  • API Gateway handles auth, rate limiting, load balancing
  • Each microservice owns its bounded context
  • CDC captures all database changes automatically
  • WebSocket delivers updates to connected clients

Bounded Contexts

Five core domains with clear boundaries and ubiquitous language.

  • Identity — Users, DIDs, authentication, profiles
  • Research Objects — Publications, datasets, versions
  • Simulation — Physics engines, visualizations
  • Funding — Grants, contributions, rewards
  • Publishing — Peer review, reputation, citations

CDC Pipeline Flow

Change Data Capture ensures all changes are streamed in real-time.

  • Capture — PostgreSQL WAL logical replication
  • Transform — ETL enrichment and filtering
  • Stream — Redis Streams for buffering
  • Deliver — WebSocket broadcast to clients

MCP Server Architecture

Model Context Protocol enables AI assistants to interact with DIU.

  • Physics Server — Run simulations, adjust parameters
  • Knowledge Server — RAG search, explanations
  • Progress Server — Track achievements, XP
  • External — GitHub, ArXiv connectors (planned)

Technology Stack

Production-grade tools chosen for performance, reliability, and developer experience. Hover over each technology to see how it's used.

🦀
Rust
Backend Services
Rust in DIU OS

High-performance, memory-safe backend services with zero-cost abstractions.

  • Framework: Axum for HTTP, Tokio for async
  • Services: All microservices (Identity, Research, Simulation, Funding)
  • CDC: ETL pipeline processing
  • Why: Type safety, performance, WebAssembly compilation
⚛️
React
Frontend UI
React in DIU OS

Interactive user interfaces with component-based architecture.

  • State: Zustand for global, React Query for server
  • Real-time: WebSocket hooks for CDC events
  • 3D: React Three Fiber for physics visualizations
  • Why: Large ecosystem, hooks, SSR support
📘
TypeScript
Type Safety
TypeScript in DIU OS

Static typing for JavaScript, catching errors at compile time.

  • Frontend: Full React codebase
  • MCP: MCP server implementations
  • Shared: API types, domain models
  • Why: IDE support, refactoring safety, documentation
🐘
PostgreSQL
Primary Database
PostgreSQL in DIU OS

Advanced relational database with CDC support via logical replication.

  • CDC: WAL logical replication for change capture
  • Security: Row Level Security (RLS) policies
  • Features: JSONB, full-text search, extensions
  • Why: ACID compliance, CDC support, Supabase
🚀
WebAssembly
Performance
WebAssembly in DIU OS

Near-native performance in the browser for compute-intensive tasks.

  • Physics: Quantum simulation calculations
  • Rendering: Complex 3D scene computations
  • Tooling: wasm-pack, wasm-bindgen
  • Why: 10-100x faster than JS for math
📦
Docker
Containers
Docker in DIU OS

Containerized deployments for consistent environments.

  • Dev: Docker Compose for local stack
  • CI: Build and test containers
  • Prod: Kubernetes-ready images
  • Why: Reproducibility, isolation, scaling
⚡
Redis
Event Streams
Redis in DIU OS

In-memory data store for caching and event streaming.

  • CDC: Redis Streams for event buffering
  • Cache: API response caching
  • Sessions: User session storage
  • Why: Sub-ms latency, Streams API, persistence
🔷
Supabase
CDC & Auth
Supabase in DIU OS

Open-source Firebase alternative with real-time capabilities.

  • Realtime: Built-in CDC broadcasting
  • Auth: OAuth, magic links, ORCID
  • Storage: File uploads, CDN
  • Why: Instant APIs, real-time, self-hostable
🎨
Three.js
3D Graphics
Three.js in DIU OS

3D library for WebGL-powered visualizations.

  • Physics: Quantum experiment visualizations
  • Particles: Wave functions, probability clouds
  • Interaction: Real-time parameter controls
  • Why: GPU acceleration, React integration
🔗
Polygon
Blockchain
Polygon in DIU OS

Layer 2 Ethereum scaling solution for Web3 features.

  • Contracts: Funding pools, IP-NFTs
  • Tokens: Research contribution rewards
  • DID: Decentralized identifiers
  • Why: Low fees, EVM compatible, fast finality
